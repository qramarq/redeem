nvme0n1p3 is BitLocker. blkid says TYPE=BitLocker and the boot sector has the -FVE-FS- signature. clear_key: no, so redeem-bitlocker unlock --clearkey will not open it. Key protector A1B2C3D4 is a recovery password. Match that 8-character id at https://account.microsoft.com/devices/recoverykey, or in Entra ID, Active Directory, or a USB .bek file. Do not paste the recovery key into this chat. Type it only at the local redeem-bitlocker prompt. With the key, redeem-bitlocker unlock /dev/nvme0n1p3 mounts read-only. The same step is cryptsetup open --type bitlk --readonly /dev/nvme0n1p3. Do not pass --password or --key on the command line. Do not run ntfsfix or chkdsk on the locked BitLocker volume. SMART on nvme0n1 PASSED, so after Windows has the volume open, BitLocker-Windows.bat remove can run manage-bde -off once you confirm. A sector clone stays encrypted. BitLocker cannot be cracked from this stick.
